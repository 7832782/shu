# 第6章 铅笔

> "要不要把绿豆水的杯子还给你？"
>
> ——她的话，中考后的暑假

中考后的暑假，学校办招生大会。

我在家里煮了一壶绿豆水，装进一个透明杯子，封好口。另外写了一份道歉信。我自己的字不好看，所以直接做了电子档。不过那个二维码，是我用铅笔在方格纸上一格一格涂出来的。字写不好，二维码总可以一笔一画来。

那几天，我趴在书桌前，铅笔削得尖尖的，对着电脑屏幕上生成的二维码，一格一格地描。涂错了，就用橡皮擦掉重来。方格纸被擦得起了毛，我换一张，重新开始。一整页的格子，涂到一半，眼睛发酸，我揉一揉，接着涂。我妈路过，问我在干嘛。我说，做作业。她不信，也没多问。

绿豆水和二维码，我托了慕雁转交。为表谢意，我另外送了她一份时代少年团的周边。

托人转交的时候，我特别嘱咐了一句：别说是我做的。慕雁答应了。可我心里清楚，这种事瞒不住，也压根没想瞒——我只是不好意思当面给，又怕她不要，只好借别人的手，把东西递过去，再把脸藏起来。

---

她收到以后，在QQ上问我：要不要把绿豆水的杯子还给你？

我说不用。

屏幕那头安静了一会儿。然后她发来一句：那好吧。

我以为这件事就翻篇了。道歉信送出去了，绿豆水送出去了，她问过了，我说不用了——礼尚往来，到此为止。

后来她发了一条动态，暗示我去看邮箱。我打开邮箱，里面躺着一封邮件，标题是《非情书》。

我盯着那个标题看了很久。非情书。三个字，一个"非"字，把什么都说明白了：这是一封情书，但它不是。或者说，它本来可以是，但她用了一个"非"字，把它钉在了别的分类里。那时候我不懂这个字的分量。后来我才明白，有些话，就是要加上一个"非"字，才说得出口；有些信，就是要叫"非情书"，才递得出去。

那封邮件的内容，现在要我一字一句复述，我已经做不到了。它后来被搞丢了，就那么没了。我只记得个大概：她说了一些对我印象的话，也提到了生我气的地方，最后是说她不生气了。

再多的，就记不全了。

很多年后，我把所有写过的、收到过的东西都翻出来。那封邮件，是唯一彻底弄丢的。

其他的东西——信，便签，日历，录音带——都还在。哪怕是随手写的一句话，都有人替我收着。唯独那封《非情书》，像从来没有存在过一样，消失得干干净净。我有时候想，如果它还在，我大概能从那里面，找到一些别的东西。一些我当时没看懂的东西。
