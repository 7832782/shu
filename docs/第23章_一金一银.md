# 第23章 一金一银

> "长这么大还没出过广东。"
>
> ——我的话，2023年4月7日

四月七号晚上，我跟她提起：两个星期之后，说是要去三峡研学，还得交2100。

她说："我也还没去过三峡。"

我长这么大，还没出过广东。这次研学，算是头一回出远门。

到了三峡，山是真高，水是真急。同学们忙着拍照，我忙着躲镜头。看什么都新鲜，又觉得，要是她也在就好了。

---

纪念品一条街，我买了两样东西。

一样是纪念币，两个，一金一银。

一样是百家姓挂件，两个。我挑了廖和黎两个姓。

回去以后，我把金色的纪念币给了她，银色的自己留着。挂件也是，把"黎"给了她，"廖"留给自己。

金色的给她，银色的给我。廖和黎，两个人加在一起，才是一整套。缺一个，就都不完整。

后来那两枚纪念币，据说一直躺在她的抽屉里。我的那枚银色的，现在还在我的书桌上。

隔着几十公里，我们俩用两枚纪念币，假装待在一起。

（第23章完）
