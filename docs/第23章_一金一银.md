# 第23章 一金一银

> "长这么大还没出过广东。"
>
> ——我的话，2023年4月7日

四月七号晚上，我跟她提起：两个星期之后，说是要去三峡研学，还得交2100。

她说："我也还没去过三峡。"

我长这么大，还没出过广东。这次研学，算是头一回出远门。

大巴一路向北，穿过一个又一个隧道。窗外的山越来越高，天越来越远。我靠在车窗上，看着外面完全陌生的风景，心里想的却是：要是她也在就好了。

到了三峡，山是真高，水是真急。同学们忙着拍照，我忙着躲镜头。看什么都新鲜，又觉得，要是她也在就好了。

---

纪念品一条街，我买了两样东西。

一样是纪念币，两个，一金一银。

一样是百家姓挂件，两个。我挑了两个字：一个是"黎"，百家姓里没有"梨"，只有这个字最像她；另一个，是我的。

回去以后，我把金色的纪念币给了她，银色的自己留着。挂件也是，把"黎"给了她，另一个留给自己。

金色的给她，银色的给我。两个姓，两个人，加在一起，才是一整套。缺一个，就都不完整。

后来那两枚纪念币，据说一直躺在她的抽屉里。我的那枚银色的，现在还在我的书桌上。

"据说"——这个词，是听来的。她的朋友告诉我，那两枚纪念币一直放在她的抽屉里。我不知道她为什么留着，也不知道她有没有把"黎"字挂件挂起来。可我知道我的这枚银币，这些年一直放在书桌上，生了锈，也没舍得扔。

隔着几十公里，我们俩用两枚纪念币，假装待在一起。
