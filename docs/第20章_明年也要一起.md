# 第20章 明年也要一起

> "明年也要一起～"
>
> ——她的话，2023年1月1日

2022年12月31号下午，她发来一句：我们一起跨年吧。

我说，跨啥年。又说，好吧。

那天下午的阳光很好，冬天的太阳，照在人身上暖洋洋的。我靠在窗边，看着手机，把那句"我们一起跨年吧"看了两遍。跨年，这两个字对我来说是陌生的——我从来没跟谁跨过年。可她说要一起，我就觉得，跨年好像是个不错的主意。

晚上十点多，她问，我们看电影不。我问看啥。她说，《烟花》。或者你有想看的嘛。

我说随你。她发来一个放映室的邀请。我问她，该不会为了这个放映室，开了个大会员吧。她说，对。

我说，之前看《情书》那次也是。下次不要花这种冤枉钱了。

她说，她不觉得是冤枉钱。我没再接话。可我心里知道，她开那个会员，是为了跟我一起看电影——隔着屏幕，同时按下播放键，在同一个时间，看同一部电影。这大概就是她说的"一起"。

她发了个"嘘"，说好好看。

电影开播。我说，行，我也冲。她说，呜呜我以为你还有的。我说，不行哦。

零点。

窗外远远地传来零星的烟花声。我盯着屏幕，等着。她的消息准时到了：新年快乐。

然后是那句：

"明年也要一起～"

我说，嗯。

一个字。我打了很多字，最后都删了，只留了一个"嗯"。我想说，好，明年也一起，后年也一起。可那些话在指尖转了一圈，最后只变成了一个"嗯"。屏幕那头，她大概在等我说点什么。可我说的，只是一个"嗯"。现在想来，她那一句"明年也要一起"，大概是我收到过的最重的承诺——她把明年，提前交给了我。

---

一月三号，她返校途中经过县城，下车见了我一面。长兴街，雅香蛋糕，我买了点什么塞给她。

她说："你是重要的人。"

我这个人，一紧张就说胡话，回了句："重要但不必要。"

发出去我就后悔了。她半天没回，过了很久，发来一个问号。

我赶紧解释：这是数学里的概念，说的是必要条件和充分条件。

解释完更尴尬了。

那天晚上我躺在床上，越想越觉得自己是个傻逼。她说你是重要的人，我说重要但不必要——我说的是必要条件，她听的是"你不必要"。这一笔糊涂账，我后来想解释，又觉得越描越黑，索性不解释了。可我知道，那句话，她大概记了很久。
