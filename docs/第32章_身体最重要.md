# 第32章 身体最重要

> "身体最重要。"
>
> ——她的话，2023年12月2日

十二月二号，下午五点多，我给她发消息：

"考砸了。"

"还感冒了。"

冬天的天黑得早，五点多，窗外已经暗下来了。我缩在座位上，鼻子塞着，脑袋昏沉，考卷上的分数还在脑子里转。我把这两个消息发出去的时候，其实没指望她回什么。可她的消息很快就来了。

她问："感冒严重吗。"

我说，现在还好，就是考试那会儿还发了烧。

她回：

"身体最重要。"

就四个字。又补了一句，放假的话就去看医生。

我说，其实已经好得差不多了。

"身体最重要"——她从来不说"下次考好点"，不说"别难过"。她只说，身体最重要。这四个字，比任何安慰都管用。我盯着它看了很久，鼻子忽然有点酸。不是因为委屈，是因为有人把"你"放在"考试"前面。

---

那阵子流感很凶，班里倒了一片。我们俩像约好了似的，轮流生病，轮流说保重。人在病里，说出来的话都是软的。那几天我们难得的，谁也不逞强。

我在微信上跟她说，你也要照顾好自己。

她回了个"嗯"，后面跟着一个小太阳的表情。

那个小太阳，黄澄澄的，咧着嘴笑。我盯着它看了好一会儿。她那边大概也在感冒，嗓子哑哑的，可她还是回了我一个小太阳。好像有了它，冬天就没那么长了。

忽然特别想回家。

想回家，想钻进被窝里，想把手机放在枕边，听她第二天说"好点了吗"。
