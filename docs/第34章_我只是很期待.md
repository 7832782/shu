# 第34章 我只是很期待

> "我只是很期待。"
>
> ——她的话，2023年12月17日

那件事之后，她一直没有再提。十二月十七号，星期天，中午。

她发来一个他们班给老师做的庆生视频，bgm是她挑的。我听出这个bgm来自某个动漫的改版，只是会心一笑，说有点抽象，她追着问，什么抽象。我只好改口，夸她挑得有品味。她说我好假。我说，好听就完事了——反正没人懂。她说，坏蛋。

聊都聊起来了，于是我问她，那件事，你还会过意不去吗。她说，不会啊，那么在意干啥——她只是很期待，说见不到我的时候，一下子接受不了，但是很快就好了。

我说，我怕影响到你的心情和学习，这我可担不起。她说，笨蛋，我有分寸。

我说，那只能怪我不懂你了。我见过类似的同学，心灰意冷的样子，跟死了一样。她说，嗯，你不懂我。哪有那么惨。

---

后来我跟她讲起一个同学的事：

当时我们全年级去三峡研学，他的女朋友没去，因为她的成绩不算好，同时伴随着一个压抑的原生家庭。后来她父母做了个决定，直接把她送到了国外。走的时候，她父母把她手机里所有的联系方式都删了。

走的不仅仅是他的女朋友，还有他的魂魄，我从来没有看过如此颓唐、失神的他。

她问，她愿意走吗——可这不是她自己的人生吗。我说，不愿意也没用。所以我特别不喜欢滨城，在每个人身上，都能感受到为了追求名利无所不及的气氛。她说，小城比较有人情味。这是庞年年弟弟给的评价。

那天她好像还有很多话想讲，但她说她晕车了，不得已要拜拜。

下午一点半，她发来一句：我进学校啦。拜拜。

那年十二月剩下的日子，过得很快。一转眼，就是跨年。
