# 第13章 积木

> "我也给你准备了积木的。"
>
> ——她的话，2022年10月28日

她的生日在农历十月初三，那年落在10月27号。

我记错了日子。等我想起来，已经是第二天。晚上九点多，我发消息给她，先是四个字：生日快乐。又补了一句，虽然已经过去一天了。

她说谢谢，说她不介意。

我惭愧，没话找话，问了一句"不用晚修吗"。她反问我怎么有空。我说我已经回家了，这个星期段考完不能留校。她那边也才刚考完，说她们下周四五才考。

聊着聊着，她忽然话锋一转，让我问她配音比赛的事。

我问了。她说她们小组拿了第三名，虽然是复赛，决赛是学校的。配的是《疯狂动物城》。

我说挺好的，努力过就行。

她说，知道了。

---

过了一会儿，我忽然发了一句：

"其实，我准备了生日礼物，是一本小说。不过能不能送出去，就得看以后有没有机会了。"

她问，是你写的吗。我说不是。她说："我也给你准备了积木的。"

积木。我没想到是这个。

我又补了一句，我其实都不过生日的，当然想送东西平时都可以。她回了个"好"。

那天我们还聊了生日的事。她说她朋友农历新历都过。我说我不知道自己过的是什么生日，反正差不多生日的时候，我妈会提醒我。

十一点多，她说了句晚安。

第二天中午，她发来一张图片，配了三个字：嘻嘻嘻。

第三天早上八点多，她问我，你现在在家吗。我九点多才醒。过了一分钟，她发来一句：

"我想见你。"

我说，虽然我也想，但估计做不到。她问，你几点走。

那天，我最后还是去了。

（第13章完）
