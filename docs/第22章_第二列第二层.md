# 第22章 第二列第二层

> "拿。"
>
> ——她的话，2023年5月3日

我们学校对面有个快递驿站。不知道从什么时候起，它变成了我们的中转站。

驿站的门脸不大，夹在两家店铺中间，货架一排一排地码着，灯光昏黄。老板是个沉默的中年人，见谁都只问一句：取件码多少。可就是这么个地方，成了我们之间最忙的路——她放东西，我去拿；我放东西，她来取。一来一回，像两个地下工作者，隔着货架交换情报。

四月七号晚上，她发来一句："其实只是想跟你说：我今天上午在校门口快递站放了个东西给你，进门右手边第二列第二层喔。"

那个"喔"字，带着一点小小的得意。我几乎能想象她放完东西，转身离开时的样子——大概还回头看了一眼那个货架，确认东西放得稳当，才放心地走。

那天我回得晚。晚上九点多去，驿站已经关门了。我拍了个照给她看，说明天再来拿。

铁门拉下来了，透过门缝，隐约能看见里面的货架。我站在门口，拍了一张照片发给她，说，关门了，明天再来。她回：好，那你明天记得。

第二天下午，我拿到了。发消息给她："又让你破费劳神了，真不好意思。"

她说："啊。"

一个"啊"字，像被我的客气话噎住了。她大概想说的是：这有什么不好意思的。可我那时候，连收她的东西都要道歉——我们之间，客气得像两个陌生人，亲昵得像两个熟人，这两种东西搅在一起，谁也分不清。

我问她东西是哪来的，她只说，你人好好。

---

五月二号，轮到我放东西。

下午四点多，我问她："我去驿站放些东西的话，你明天能拿不。"她说可以。我放好了，告诉她位置："就在那个大哥哥的电脑的正后方。"又补一句，袋子用的是之前的那个。

放东西的时候，我特意挑了货架最里面的位置，怕别人顺手拿走。放好之后，我站在货架前，把那个袋子看了两眼，确认它不会倒下来，才走出驿站。然后我给她发消息，告诉她位置——"大哥哥的电脑的正后方"，我说得含含糊糊，像在说什么接头暗号。

那天晚上我提醒她：驿站老板说最早也得十点开门，能拿到吗。她说能，她下午才去学校。

第二天早上八点，我问她拿了没。她说没有，下午才去。

然后我说：

"今天我发烧了。"

"怕传给你，所以别拿了好嘛。"

她连问了四句：你去看医生了么。你今天还上学吗。吃早餐没。家长在家吗。

四句，一句接一句，像连珠炮。我一条一条地看，忽然觉得，被一个人这样惦记着，是件很奢侈的事。我说估计不去上学了。

她说："吃好早餐，去看医生，发烧不能拖着的。"又说："没关系。"

中午，她发来一句：看医生了，要在我这边打卡。

打卡。她把我当成了需要监督的小孩。我盯着"打卡"两个字，忽然笑了——笑完又有点酸。她管着我，像管着一件重要的事。这世上愿意这样管你的人，不多。

我回：好的。

---

五月六号傍晚，她发来消息，说东西拿到了，"谢谢"。

我说，我们五点半放的学，然后我就被老师叫过去背离骚了，不过已经好多了。

她回了一串哈哈哈。

那一串哈哈哈里，我仿佛能看见她笑的样子。生病的事翻篇了，东西也拿到了，她笑得没心没肺。我盯着那串哈哈哈，也跟着笑。

那段时间，我们靠着一个驿站，把想给的东西递来递去。东西都不贵，可贵的是，每次放东西的时候，我们都要多走那一段路，多留一个心眼，多写一行"第几列第几层"。

那些字条，像我们之间的暗号。

（第22章完）
