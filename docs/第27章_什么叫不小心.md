# 第27章 什么叫不小心

> "你总是妄自菲薄。"
>
> ——她的话，2023年8月19日

八月十九号晚上，我跟她说，我上个学期报了一个化学竞赛。

她说，嗯。我说，全校选了四个同学，"一不小心把我选上了"。

她问："什么叫不小心。"

我还没来得及回，她又发来一句：

"你总是妄自菲薄。"

这五个字砸得我半天没说话。我辩解说，可是我现在的化学确实不行。

后来我才知道，那不是什么小考试，是中国奥林匹克化学竞赛初赛，还得去广州考。我长这么大，第一次去广州。

那天晚上，她催我去睡觉。临睡前，她发来一句：

"不要那么大压力，也不要妄自菲薄，调整好心态，相信自己。"

---

那天晚上我们其实聊了很多。

她那边刚开学，说累是累，其实还挺开心的，因为交到了一个好朋友。就是英语老师换了，她都不知道怎么形容——每节课都像没准备好一样，有时候还走神十几分钟，单词拼写错误，还把半倒装讲成完全倒装。

班主任陆婷老师差两分考上市里的编制，但是选择留下来带她们。她说明年不考了。可她明明可以去市里——她老公和女儿都在那边。

她说："可是我有一种绊住她们前途的负罪感。虽然我很喜欢她们。"

我说，那不是挺好的，感情深的都没走。

她讲起"不要在感情中失去自我"，说她写过一张《氓》的感想。我接不上，她说：

"就像是我给你打电话，你没有接电话，我会很着急很着急，然后想很多很多。"

我说，那个时候确实不好意思，平时我的手机都是静音的。

她说，你不是解释清楚了嘛，没有关系哒。

可我听着那句话，总觉得像被什么东西轻轻刮了一下。

（第27章完）
