# 第27章 什么叫不小心

> "你总是妄自菲薄。"
>
> ——她的话，2023年8月19日

八月十九号晚上，我跟她说，我上个学期报了一个化学竞赛。

她说，嗯。我说，全校选了四个同学，"一不小心把我选上了"。

她问："什么叫不小心。"

我还没来得及回，她又发来一句：

"你总是妄自菲薄。"

这七个字砸得我半天没说话。我辩解说，可是我现在的化学确实不行。

我盯着"妄自菲薄"四个字，看了很久。她说我总是不相信自己——她说对了。我说"一不小心把我选上了"，其实是想把这件事说得轻一点，轻到像一件不关我的事。可她一眼就看穿了。她隔着屏幕，看见了我藏在"不小心"后面的那个怯懦的自己。

后来我才知道，那不是什么小考试，是中国奥林匹克化学竞赛初赛，得去广州考。可最后我没去成——那几天刮台风，广州去不了了。

报名的时候，我只知道是个化学竞赛；等我反应过来它是全国性质的，心里先虚了。我想起她说的话：你总是妄自菲薄。也许她说得对，我连自己报了多大的赛，都不敢去弄清楚，怕弄清楚了，就更觉得自己不行。后来台风来了，去广州的打算就搁下了。

那天晚上，她催我去睡觉。临睡前，她发来一句：

"不要那么大压力，也不要妄自菲薄，调整好心态，相信自己。"

---

那天晚上我们其实聊了很多。

她那边刚开学，说累是累，其实还挺开心的，因为交到了一个好朋友。就是英语老师换了，她都不知道怎么形容——每节课都像没准备好一样，有时候还走神十几分钟，单词拼写错误，还把半倒装讲成完全倒装。

她说这些话的时候，语气是轻松的，像在吐槽一件好笑的事。我在这头听着，想象她坐在新教室里，托着腮，听那个不太靠谱的英语老师讲课的样子。她抱怨老师的时候，也带着笑——她好像总是这样，再糟糕的事，到了她嘴里，都能说出一点好笑来。

她的班主任差两分考上市里的编制，但是选择留下来带她们。她说明年不考了。可她明明可以去市里——她老公和女儿都在那边。

她说："可是我有一种绊住她们前途的负罪感。虽然我很喜欢她们。"

我说，那不是挺好的，感情深的都没走。

她讲起"不要在感情中失去自我"，说她写过一张《氓》的感想。我接不上，她说：

"就像是我给你打电话，你没有接电话，我会很着急很着急，然后想很多很多。"

她说这句话的时候，语气很平，像在讲一件早就想通了的事。可我听着，心里一紧。她说的是《氓》的感想，可那句"你没有接电话，我会很着急很着急"——她说的是我。

我说，那个时候确实不好意思，平时我的手机都是静音的。

她说，你不是解释清楚了嘛，没有关系哒。

可那句"没有关系哒"，让我想起那些没接的电话、那些让她"很着急很着急"的夜晚。她说没关系，可它们都在。像墙上的钉子，拔掉了，洞还在，一天一天地积累着。
