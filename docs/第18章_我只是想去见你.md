# 第18章 我只是想去见你

> "我只是想去见你。"
>
> ——她的话，2022年12月11日

十二月十一号，星期天上午，我坐车回学校。

大巴的引擎声嗡嗡的，车厢里没几个人，都靠着窗打盹。我掏出手机，半路上给她发了条消息，说我上车了，问她是不是早到了。她说没有，要是找你的话，肯定提前跟你说。

我说，你之前那次，不是上午就坐车吗。

她说：

"我只是想去见你。"

这七个字，我盯着看了很久。她不是来赶车的，她是来见我的。

我说，那好吧。

过了十几分钟，她又来了，说要给我打电话，问我什么时候有空。她说，她下周应该不回家。

我说，中午和下午放学都发手机，大概是十一点半到下午两点半，下午四点半到晚上七点。

我把我一天的缝隙，都报给了她。那些原本用来发呆、用来打水、用来趴在桌上眯一会儿的时间，从那一刻起，都变成了"等她电话的时间"。

她说好，下午给你打。

下午她上车，我也刚好到。她说了句嘻嘻，拜拜。下午三点多，她进学校，发来一句"进学校咯。"

我看着那句"进学校咯。"，想象她背着书包，穿过校门，抬头看了一眼教学楼的样子。她到了。她平平安安地到了。我把手机收起来，忽然觉得，这个星期天，比从前任何一个星期天都要长，也都要短。

---

我们就这样，把"想念"排进了课程表。

她要我的时间表，不是要安排打电话，是想知道什么时候能找到我。她把"我只是想去见你。"说出口的时候，我回的是"那好吧。"

可我当时只会讲道理。
