# 第28章 就这样错过吧

> "下次想跟我聊天的话，就星期天的12点打电话给我吧。"
>
> ——我的话，2023年9月16日

九月十号，我在广州考化学竞赛。

上午九点考到十二点半。考完我给她发消息："真坐牢，没几道会写的。"

她说，考完就好。

那天早上七点出发，走了一个小时的路才到考场。广州没拍什么照片——酒店、考场、路边的树，就这些。

我坐在考场里的时候，偶尔会走神，想着她在做什么。她那边刚开学，大概正坐在新教室里，听老师讲卷子。我们隔着一座城，各自坐在各自的教室里，为着各自的前程努力。那时候我觉得，这样也挺好——我们都在往前走，方向虽然不同，可总会有交汇的那天。

---

九月十六号，我从广州回来的那个周末，我们错过了一次。

下午四点五十九分，她发来："我放学啦。""你在干啥。"

五点十分，她问："你不会还没下课吧。"

五点二十二分，她急了："你怎么那么慢。"

然后她说："好吧。""就这样错过吧。""我进去学校了。"

三条消息，间隔二十多分钟。她放学，找我，等了一会儿，又等了一会儿，最后说"就这样错过吧"，进了学校。而我，正坐在教室里，盯着黑板上的时钟，不知道她在那头等我。

我五点二十才下课，看到消息已经晚了。她进了学校，错过了。

我发消息说："我们5点20下的课。"

然后我补了一句：

"下次想跟我聊天的话，就星期天的12点打电话给我吧。"

她没回。后来我把广州的照片补发给她，她也没说什么。那段时间她总是这样，把我的事都当成重要的事。我考个竞赛，她比我还上心；我发张照片，她能夸出花来。而我呢，连她几点放学都不知道。

中秋前后，我们通了次电话。电话里她的声音，隔着电流，带着笑。她说她们村赢球的时候放鞭炮，放音乐，热闹得不行。我在这头，想象她站在热闹里的样子，也跟着笑。那一刻，什么竞赛，什么错过，都不重要了。她笑，我就觉得什么都值得。

那时候我觉得，异地也没什么，我们这不是挺好的吗。
